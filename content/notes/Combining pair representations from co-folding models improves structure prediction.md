#### Summary

**Combining complementary pair representations from independently trained co-folding models can improve structure prediction** [@jang2026]. This is achieved using learned mappings that transfer pair representations from one into the base model's representation space. The resulting model improves protein–protein and protein–ligand predictions, including examples where the individual models fail.
