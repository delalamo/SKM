#### Summary

**Generic [[protein-language-models|protein language models]] appear to capture global antibody-sequence properties more reliably than local residue-specific properties within [[Complementarity-determining regions|CDRs]].** This is a practical observation rather than a claim currently supported by a dedicated benchmark.
