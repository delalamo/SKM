#### Summary

**[[protein-structure-tokenization|Structural tokens]] improved zero-shot [[variant-effect-prediction|variant effect prediction]] ESM3 inference only when using the experimental WT structure** [@loux2024]. Computational models obtained using [[Rosetta]] or short [[MD simulations]] substantially lowered the Spearman correlation, despite the resulting embeddings being almost identical.
