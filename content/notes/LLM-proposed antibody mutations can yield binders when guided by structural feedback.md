#### Summary

**LLM-proposed antibody sequence changes can yield experimentally detected binders when embedded in an iterative search guided by predicted complex structures** [@openddeharness2026]. This was shown with OpenDDE-harness, which uses antibody-antigen complex prediction confidence as an oracle for binding.
