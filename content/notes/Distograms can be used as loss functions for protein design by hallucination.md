#### Summary
**[[distograms|Distograms]] from [[notes/Structure prediction|protein structure prediction neural networks]] can be used as loss functions for protein design** [@cho2025b; @candido2026]. This has been experimentally validated for both miniprotein binders and antibodies in the case of ESMFold2.
